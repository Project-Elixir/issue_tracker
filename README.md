### Project Elixir Issue Tracker
Welcome to the official Issue Tracker for Project Elixir | Redefine Simplicity with your android experience on our minimalistic custom rom — where sleek design meets robust security, performance, and stability..

This space is dedicated only for tracking bugs, issues, and feature requests related to official Project Elixir builds.

### Please Read Before Creating an Issue

Ensure you’re on an official build. We don’t provide support for unofficial or third-party builds. Provide complete details including:

1. Device name and codename
2. Build version and date
3. Steps to reproduce the issue
4. Logs or screenshots (if applicable)

- Avoid duplicate reports. Check existing issues before submitting a new one.
- Do not discuss support or updates here. For general queries, join our Telegram Support Channel or contact us via email.
- Respect maintainers and developers. Constructive feedback only — no spam or off-topic discussions.

### Reporting Format Example
```
Device: Pixel 6 (oriole)
Build version: 6.0 (Android 16 - baklava)
Build date: 2025-10-01
Issue: Settings crash when changing wallpaper
Steps to reproduce:
1. Open Settings > Wallpaper & style
2. Tap “Change wallpaper”
3. App crashes instantly
Logs: [attach logcat if available]
```

> [!Note]
> - Issues without proper logs or reproduction steps may be closed without notice.
> - Feature requests should be realistic and should not compromise system stability.
